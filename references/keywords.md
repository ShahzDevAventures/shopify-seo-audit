# Keywords, SERP and authority

Source: Shopify Academy SEO path (2026-10-27), paraphrased.

## Baseline (15 minutes, no more)
From GSC Performance, plus one third-party tool if available (Semrush, Ahrefs or Keyword Planner):
- the top 3 queries by clicks
- the share of clicks from branded vs non-branded queries (this tells you the brand stage)
- obvious missing terms to work into titles, descriptions and alt text

## Brand stage decides scope
- **New:** GSC set-up, brand awareness, links, a competitor keyword gap, pages built to a keyword map.
- **Growing:** collect and show reviews, grow the non-branded terms it is starting to rank for, study how competitors build their pages, improve navigation.
- **Established:** widen coverage, improve pages that already perform using traffic data, test continuously.

## Intent → page type
| Intent | Example | Page |
|---|---|---|
| Informational | "how to care for ceramic mugs" | blog post or guide |
| Commercial | "best mugs for camping" | comparison or guide |
| Category | "dishwasher-safe silverware" | **collection** |
| Transactional | "handmade ceramic mug" | **product** |
| Navigational | brand + product | brand's own page |

## 5-step SERP read (per target keyword)
1. Search it, logged out.
2. Note the dominant intent and the SERP features present (shopping carousel, People Also Ask, AI overview, video).
3. Note which page types rank, and whether they're big brands or small stores.
4. Find what the top 3–5 share: copy length, format, headings, imagery, exact vs semantic match.
5. Find the gap to fill.

Output: page type + the content elements to include + a minimum copy length. If collections with 100+ words of copy rank, optimise the collection, not the PDP.

## Choosing targets
- Head terms belong to big brands. Target **long-tail terms (3+ words)**: clearer intent, less competition, better conversion.
- Brainstorm 3–5 head terms → 3–5 long-tail variants each → SERP check (do small shops appear on page 1? If so, it's an opportunity) → mine Google autocomplete.
- Score each candidate: volume (and trend), difficulty, intent, journey stage, the business goal it serves, the target page. **Pick 3–5 primary targets.**
- **Clusters:** one page per parent topic, named to cover its variants ("Ripped & Distressed Denim Jeans"). Never point two pages at one term.
- Branded terms come almost free once the store name is in titles. Growth comes from non-branded terms.
- AI can propose new collections from the full product list; a person checks them against merchandising.

## Striking distance (the highest-ROI step when GSC is available)
In GSC, filter Position 11–20, sort by impressions. Put each query into one case:
- **(a) Optimise:** add the term to the best-matching page's title, H1/H2 and copy, or build a new page if nothing matches.
- **(b) Maxed out:** usually a head term the store can't realistically win.
- **(c) Ignore:** not relevant.

## Keyword map (the deliverable)
`Keyword | Volume | Difficulty | Intent | Target page (existing URL or "new") | Action`. Every chosen keyword maps to exactly one page.

## Authority (off-page, light)
- **Good links:** relevant industry, authoritative site, editorial context, natural varied anchors, links to deep pages (PDPs, collections).
- **Bad links:** spammy or irrelevant sites, link networks, repeated exact-match anchors, sudden spikes, link-exchange rings.
- **Free competitor research:** `link:competitor.com`, `"competitor brand" "source"`, `site:competitor.com inurl:blog`. Note which content gets cited, by whom, and why.
- **Link-worthy assets:** "[topic] statistics" pages built from original data, reference charts and glossaries, finders and calculators, comparison visuals.
- **Promotion:** relevant bloggers and publications, guest posts and podcasts, journalist-source requests, a few partnerships with non-competitors.
